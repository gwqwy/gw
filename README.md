# gw Designer — M3E 可视化低代码前端页面设计器

以 [lnkiai/m3e-canvas](https://github.com/lnkiai/m3e-canvas) 的组件体系为基础构建的类 Axure RP 9 可视化设计工具（Windows 桌面应用，.NET 8 WPF + WebView2）。

在画布上拖放 **Material 3 Expressive** 组件搭建界面，然后一键生成：

- **独立 HTML 文件**（含交互：开关/页签/滑块可操作，组件可跳转页面）
- **Vue 3 单文件组件（.vue）**（`<script setup>`，开关/页签带响应式绑定）
- **AI 编程提示词**（中文自然语言设计稿描述，可指定目标平台：Vue 3 / 纯 HTML / 通用 Web）
- **组件块代码**（单个组件的 HTML / Vue / JSON，右键即复制，JSON 可再粘贴回设计器）
- **项目文件（.m3ed）** 与 **整包导出**（「导出全部」面板中自行勾选格式，写入所选文件夹）

> **架构说明（完全离线）**：界面由 .NET WPF 内嵌的 WebView2 渲染，`https://m3edesigner.local`
> 只是映射到本地 `www/` 文件夹的虚拟主机名，**不连接任何外部服务器或浏览器**，断网可用。
> 「预览」为程序内浮层（iframe），需要时也可点「在浏览器打开」用系统浏览器查看。
> 图标 / 字体说明：图标为内联 SVG（103 个 Material Symbols），生成代码中的 Google Fonts
> 链接仅用于在线加载 Roboto 字体，离线时自动回退系统字体，不影响功能。

## 界面一览

| 区域 | 功能 |
| --- | --- |
| 顶部工具栏 | 新建 / 打开 / 保存、撤销重做、选择/平移、缩放、主题、预览、代码、导出全部 |
| 左侧组件面板 | 67 种 M3 Expressive 组件 + **Uiverse 社区组件**（3388 个，实时预览）+ **自定义组件**分类，支持搜索、拖入或双击放入画布 |

## 自定义组件（长期保存）

1. **导入代码组件**：左侧「社区」/「自定义」分类底部的「导入代码组件」按钮 → 粘贴 HTML/CSS 代码块或 Vue SFC（自动识别）→ 默认勾选「保存到自定义组件库」→ 长期留在组件库中，可反复拖入画布，双击图块可重命名，悬停 × 删除。
2. **组合复用**：选中画布上一个或多个组件 → 右键「保存为自定义组件…」命名（单个代码组件会保存其 HTML/CSS 本体）→ 左侧「自定义」分类可反复拖入。
3. **存储位置**：桌面版写入 `%LOCALAPPDATA%\M3EDesigner\library.json`（并同步浏览器本地存储兜底），跨项目可用、重装 WebView2 缓存不丢失。
4. **样式隔离**：导入与社区组件的 CSS 会自动做作用域隔离（类名前缀 / @keyframes 改名 / id 重映射 / position:fixed 矫正），不会污染设计器界面与其它组件；每次拖入画布都使用独立作用域类，互不干扰。

**签名属性**：每个内置组件都有一个**专属属性**（属性面板自动出现对应编辑控件），用来区分功能相近的组件。例如：按钮=图标位置、图标按钮=红点角标、FAB=数字角标、扩展 FAB=加载中态、拆分按钮=主区宽度、标签片=可关闭、分段按钮=描边样式、顶部应用栏=标题居中、导航栏=纯图标、面包屑=首页图标、标签页=胶囊/下划线指示器、卡片=隐藏图片区、列表项=尾部文字、横幅通知=信息/警告/错误级别、文本输入=占位提示、多行输入=设计行数、复选框=半选态、滑块=刻度档位、文本=对齐、时间线=连线样式、图片=填充模式、徽标=红点模式、分割线=垂直、头像=形状、轮播=指示点数、日历=选中日期、分页=边界省略、抽屉=底部条目、大图头部=遮罩浓度、空状态=行动按钮、加载指示器=速度倍率、圆形进度条=显示百分比、线性进度条=波浪样式、引用块=来源署名、代码块=语言角标……全部属性随 HTML/Vue/提示词导出。

## 编组与弹窗图层

- 选中多个组件 → `Ctrl+G` 或右键「编组」→ 图层面板出现可展开的编组节点（`Ctrl+Shift+G` / 右键「取消编组」）。
- 在编组属性中勾选「**弹窗样式**」：画布中该编组下方显示半透明遮罩；导出的 HTML / Vue 默认隐藏此编组，其他组件的「点击跳转」会多出「打开弹窗「编组名」」选项，点遮罩或成员内「关闭所在弹窗」关闭。
- 提示词同样会描述弹窗图层的行为（默认隐藏、遮罩、触发与关闭方式）。

## 构建与运行

要求：.NET 8 SDK（无需 Node；Node 仅在重新生成图标/跑自测时需要）。

```bash
cd M3EDesigner
dotnet publish -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true
```

产物在 `M3EDesigner/bin/Release/net8.0-windows/win-x64/publish/`：
**gw.exe（需与 www/ 文件夹放在一起）**。双击运行即可。

开发调试：`dotnet run`（会自动把 designer/ 复制到输出目录）。

### CI 构建（GitHub Actions）

推送到 `main`、PR 或手动触发（workflow_dispatch）时，[.github/workflows/build.yml](.github/workflows/build.yml) 会：

1. 在 Ubuntu 上跑 `node tools/test_codegen.cjs` 自测；
2. 在 Windows 运行器上 `dotnet publish` 单文件自包含版，校验 `gw.exe` 与 `www/` 齐全后打包 `gw-<分支或标签名>.zip` 上传为 Artifact。

推送 `v*` 标签（如 `v1.1.0`）时会额外自动创建 GitHub Release 并附上 `gw-<tag>.zip`（对应 `release/` 的手工发布流程）。Release 说明由 [CHANGELOG.md](CHANGELOG.md) 驱动：Actions 用 awk 截取当前版本段落（从 `## <tag>（日期）` 标题行到下一个版本标题之前）作为说明正文，因此发版前记得在 CHANGELOG.md 里补好对应版本段落。

## 后续添加组件（重要）

组件是**数据驱动**的，新增一种组件不需要改画布/导出/面板的任何代码：

1. 在 `designer/js/registry.js` 里仿照现有条目调用 `M3E_REG.add({...})`：
   `kind / name / cat / icon / spec（默认尺寸与内容）/ props（检查器字段）/ render(it)（返回 HTML 字符串，画布与导出共用）/ desc(it)（提示词描述一句话）`
2. 需要新图标时把图标名加进 `tools/genicons.mjs` 的 ICONS 列表，运行 `node genicons.mjs`。
3. 可选：`inter` 字段声明交互类型（`toggle` / `radio` / `tabs` / `slider` / `input`），导出的 HTML/Vue 自动带交互。

## 数据说明

- 项目文件 `.m3ed` 为 JSON；浏览器 localStorage 每次修改后自动暂存（下次启动自动恢复）。
- 在纯浏览器中打开 `designer/index.html` 也可运行（无 .NET 桥接时自动降级为下载/上传文件）。

## 与 m3e-canvas 的关系

组件种类、默认尺寸、圆角、分类、中文名称、7 套色板色值均取自 m3e-canvas（MIT）。本项目是其「生成真实前端代码」方向的延伸：m3e-canvas 输出提示词，gw Designer 同时输出**可直接运行的 HTML / Vue 文件**与提示词。

- 修复含弹窗图层的页面导出 Vue 时，弹窗成员被全量重渲染：非弹窗组件的 `ref` 重复声明导致 SFC 编译失败、多个弹窗时成员互相串组

- 修复「步骤条」导出 Vue 时被错误重建成普通标签页、丢失步骤结构
- 修复导航栏/标签页等导出 Vue 时子项被渲染为 `<dest>` 等无 class 非标标签、样式完全失效的问题
- 修复「容器框」属性面板出现两个圆角输入框
- 打开背景取色器不再产生多余的撤销记录/脏标记
- 层级调整在无法移动时不再写入撤销栈；连续文本输入与画布操作交错时不再丢失历史节点
- 粘贴/生成副本时组件钳制在页面边界内
